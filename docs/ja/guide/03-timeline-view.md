# タイムラインビュー

[< 前へ: インスペクション](./02-inspection.md) | [次へ: フィルタリング >](./04-filtering.md)

---

タイムラインビューは、Kubernetes クラスタ内の多種多様なリソースの状態変化やログの発生状況を、時系列に沿って直感的に俯瞰・探索するための KHI の中核となる画面です。

## 画面構成

![タイムライン画面構成](/docs/ja/images/timeline-ui-structure.png)

タイムラインビューは主に以下の 5 つの要素で構成されています。

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **タイムラインヒストグラム / 時間ルーラー** | 表示時間軸のルーラーと、ログの発生頻度を重大度別にヒストグラムとして表示します。 |
| **2** | **タイムラインインデックス** | クラスタ、apiVersion、Kind、Namespace、リソース名、およびサブリソースやコンテナの階層ツリーを表示します。 |
| **3** | **タイムライン本体** | 各リソースの状態遷移や関連ログイベントをタイムライン上にグラフィカルに表示します。 |
| **4** | **凡例** | 選択中のタイムラインで使用されている色やアイコンの意味を解説します。 |
| **5** | **ホバーポップアップ** | タイムライン上にマウスカーソルを合わせた際、その時点および付近に発生したログの詳細一覧をポップアップ表示します。 |

## タイムラインの拡大・縮小とナビゲーション

タイムライン画面では、時間軸を自在に拡大・縮小して、広範囲な傾向の把握からミリ秒単位の詳細な調査までスムーズに行うことができます。拡大・縮小は常に **マウスポインタの位置を中心** に行われます。

![タイムラインの拡大・縮小操作](/docs/ja/images/timeline-zoom-controls.png)

### 操作方法

- **トラックパッドの場合**:
  - タイムライン本体の上で **2 本指のピンチイン / ピンチアウト操作** を行うことで、マウスポインタ位置を中心に素早く拡大・縮小できます。
- **通常マウス + キーボードの場合**:
  - **`Shift` キーを押しながらマウスホイールを回転** させることで、マウスポインタ位置を中心に拡大・縮小できます。
- **タイムラインのスクロール・移動**:
  - タイムライン上をドラッグで前後の時間帯へ移動できます。

## タイムラインの構造

KHI においてタイムラインは、複数の根を持つ木構造として管理されています。
リソースごとに定義された規則に基づいて親子関係が構築され、階層的なタイムラインとして一覧表示されます。各タイムラインには、その階層に応じた名前とタイムラインタイプが割り当てられています。

### タイムラインインデックスの各要素

タイムラインインデックスの各行には、以下の操作要素とメタデータが表示されます。

![タイムラインインデックスの構造](/docs/ja/images/timeline-index-structure.png)

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **折りたたみ / 展開ボタン** | クリックすることで、子要素のタイムラインの表示・非表示を切り替えます。 |
| **2** | **タイムライン名** | クラスタ名、Namespace 名、リソース名など、該当階層の名称を表示します。 |
| **3** | **タイムラインタイプ** | `k8sCluster`、`apiVersion`、`kind`、`namespace`、`resource` など、タイムラインの種別を示すラベルチップです。 |
| **4** | **タイムラインメニュー（︙）** | 該当タイムラインのフィルタリングや子要素の一括絞り込みなどを行えるコンテキストメニューです。 |

### リソースの階層構造例（Pod の場合）

Pod リソースのタイムラインは、上位から順に以下のような階層構造を持ちます。

| 階層 | タイムラインタイプ | 例 | 説明 |
| :--- | :--- | :--- | :--- |
| **1** | `k8sCluster` | `p0-gke-basic-1` | Kubernetes クラスタのルートノード |
| **2** | `apiVersion` | `core/v1` | リソースの API バージョン |
| **3** | `kind` | `pod` | リソースの Kind |
| **4** | `namespace` | `1-2-deployment-update` | リソースが属する名前空間 |
| **5** | `resource` | `nginx-deployment-surge-9964c...` | 個別のリソースインスタンス名 |
| **6** | `subresource` / `condition` / `container` | `binding`, `Ready`, `nginx` | リソースに紐づくサブリソース、コンディション、コンテナなどの擬似サブリソース |

### タイムライン本体の表示

![タイムライン本体の表示](/docs/ja/images/timeline-body-elements.png)

ログとリソースの紐付き方に応じて、タイムライン上には以下の 2 種類の方法で情報が表示されます。

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **リビジョン** | そのリソースに関連する、継続するリソースの状態を表す帯状のバーです。 |
| **2** | **イベント** | そのリソースに関連する個々のログが存在することを表す菱形マーカーです。 |

#### リビジョン

リビジョンは、ログの発生によってリソースの状態が変化したと判断できる場合に表示されます。
例えば Kubernetes の監査ログにはその時点のマニフェストが含まれるため、監査ログが記録された時点を起点とし、次にリソースが編集された監査ログが出るまでの区間が 1 つの状態（リビジョン）として表現されます。

リビジョンの意味は、色やアイコンで表されています。リビジョンの右端に書かれている数値は、KHI が認識している最初の変更を 0 として 1 ずつ増加する変更の番号を表しています。この番号はヒストリービューで表示されているものと同じであり、短期間に複数の変更があってタイムライン上でバーが潰れてしまっている場合でも、番号の飛びから変更の存在を確認できます。

#### イベント

イベントは、リソースの状態遷移に直接変換されないログを表します。例えば Pod 関連の kubelet のログや containerd のログなどは、状態を表しているというよりもそのタイミングの出来事を表しているため、点で表現されます。

イベントの菱形の上側は Severity（重大度）を表し、下側はそのログの種類を表しています。
重大度の高いログであるイベントの点は重大度の低いログよりも手前に表示されるようになっているため、密集していてもその区間の最も重要なログを知ることが可能です。

#### 凡例の確認

リビジョンの色や、イベントのログの種類を表す色はタイムラインのタイプごとに意味が異なります。

| リビジョンの凡例 | イベントの凡例 |
| :---: | :---: |
| ![リビジョンの凡例](/docs/ja/images/timeline-legend-revisions.png) | ![イベントの凡例](/docs/ja/images/timeline-legend-events.png) |

色の種類が多いため、すべてを覚える必要はありません。意味がわからない色やアイコンがあった場合は、タイムラインをクリックすることでそのタイムラインで用いられているリビジョンやイベントの凡例を確認できます。

#### 破線・ストライプ表示のリビジョン

リビジョンの色にはさまざまなバリエーションがありますが、破線やストライプ（縞模様）で描画されるリビジョンには共通するルールがあります。

以下はコンテナタイムラインにおけるリビジョンの凡例の例です。

![コンテナのリビジョン凡例](/docs/ja/images/timeline-legend-container.png)

1. **破線のリビジョン**: 「削除された」「終了済み」「待機中」など、実体として稼働していない状態を表します。
2. **ストライプのリビジョン**: その区間の状態を確定するためのログ情報が不足している状態を表します。例えば、削除ログが存在するためリソースが存在していたことは確認できるものの、作成時のログがクエリ期間に含まれておらず初期状態が特定できない場合などに表示されます。

各リビジョンの正確な状態は凡例に記載されていますが、この 2 つの共通パターンを覚えておくことで、色の詳細を都度確認しなくても直感的に概要を把握できます。

### ホバーポップアップ

![ホバーポップアップ](/docs/ja/images/timeline-hover-popup.png)

タイムライン上の要素にマウスカーソルを合わせると、カーソル付近に存在するログの詳細ポップアップが表示されます。

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **タイムライン** | カーソル付近のログとリビジョンを縦方向に並べたタイムラインです。タイムライン本体と異なり、各項目の高さは時間の長さを表すものではありません。 |
| **2** | **Verb** | リソースの状態を変化させてリビジョンを追加した操作の種類を表します。作成は青、削除は赤のように区別され、ヒストリービューの表示色と連動しています。 |
| **3** | **ログタイプ** | ログの種類を表すインジケータです。イベント菱形マーカーの下側の色と一致します。 |
| **4** | **ログの重大度** | ログの重大度を表すインジケータです。イベント菱形マーカーの上側の色と一致します。 |
| **5** | **タイムスタンプ** | そのログが記録された時刻を表します。 |
| **6** | **ログサマリー** | 構造化ログから生成された 1 行要約です。生ログの特定フィールドをそのまま表示するだけでなく、コンテナ ID などの識別子をわかりやすい名前に自動解決して表示します。 |
