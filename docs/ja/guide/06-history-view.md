# ヒストリービュー

[< 前へ: ログビュー](./05-log-view.md) | [次へ: トポロジービュー >](./07-topology-view.md)

---

ヒストリービューは、選択したリソースに対して行われたログから観測できるステートの変更履歴を時系列で確認し、変更前後のマニフェスト差分を詳細に調査するための画面です。

## 画面構成

![ヒストリービューの構成](/docs/ja/images/history-diff-structure.png)

ヒストリービューは主に以下の 3 つの領域で構成されています。

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **リソース階層バー** | 選択中のリソースの階層構造を表示します。クリックするとリソースパスをクリップボードにコピーできます。 |
| **2** | **変更リスト** | そのリソースに対して発生したリビジョンの一覧です。 |
| **3** | **マニフェスト差分表示ペイン** | 選択したリビジョンにおけるマニフェストの変更差分を色分けして表示します。 |

## 変更リスト

変更リストには、Kubernetes 監査ログ等から抽出されたリソース状態の変更イベントが時系列で一覧表示されます。

![変更リストの各要素](/docs/ja/images/history-list-elements.png)

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **リビジョン番号** | リビジョンの連番です。タイムライン上のリビジョンバー右端に表示されている番号と一致します。 |
| **2** | **差分インジケータ** | 変更によってマニフェストに実際の差分が生じたかどうかを表します。緑色のアイコンは差分が検知されたことを示します。 |
| **3** | **タイムスタンプ** | 変更操作が行われた時刻を表示します。 |
| **4** | **Verb** | リソースの状態変更をもたらした操作（Create、Patch、Delete など）を表示します。 |
| **5** | **実行ユーザ** | その変更操作を実行した ServiceAccount、Node、または User を表示します。 |

## リソースの Diff

マニフェスト差分表示ペインでは、直前のリビジョンからの変更点が色分け（追加は緑、削除は赤）で表示されます。

![マニフェスト差分の各要素](/docs/ja/images/history-diff-elements.png)

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **managedFields 表示切り替え** | Kubernetes が管理する `metadata.managedFields` の表示・非表示を切り替えます。 |
| **2** | **Diff ナビゲーション** | マニフェスト内の変更箇所（Hunk）間を前後にジャンプして素早く移動します。 |
| **3** | **追加情報フィールド** | 下線が引かれたフィールドにマウスカーソルを合わせると、コンポーネント情報などの詳細なメタデータがポップアップ表示されます。 |
