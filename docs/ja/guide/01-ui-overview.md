# 画面構成

[< 前へ: はじめに](./00-introduction.md) | [次へ: インスペクション >](./02-inspection.md)

---

![KHI 画面構成](/docs/ja/images/overview-ui-structure.png)

KHI のメイン画面は、効率的なログ調査を行えるように複数のビューやペインで構成されています。デフォルトで KHI の画面を開いた場合に表示される画面である上図の各番号に対応する要素の概要は以下の通りです。

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **ヘッダー** | アプリケーションのメニュー、サーバとの接続状態やサーバ側のメモリ使用量を表します。 |
| **2** | **ツールバー** | 表示しているタイムラインやログのフィルタ、時刻表示のタイムゾーンの変更を行います。 |
| **3** | **タイムラインビュー** | ログをリソースごとのタイムラインとして直感的に俯瞰するための画面です。 |
| **4** | **ログビュー** | 選択中のタイムラインやフィルター条件に該当するログストリームを時系列で一覧表示し選択されたログの詳細情報を表示します。 |
| **5** | **ヒストリービュー** | 選択中のリソースに対する変更履歴及びその変更の詳細情報を表示します。 |

KHI の基本的な使い方はタイムラインビュー全体でリソースの変化を俯瞰しアノマリーを見つけ出し、ログビューとヒストリービューで詳細を確認するという流れになります。

## View メニューとドッキングウィンドウ

ヘッダーとツールバー以外の各ビューはドッキングウィンドウとして構成されており、ドラッグ＆ドロップによって自由にリサイズや配置の変更が可能です。

閉じたビューを再度開きたい場合は、ヘッダーの **View** メニューから対象のビューを選択して追加できます。

![KHI View メニュー](/docs/ja/images/overview-view-menu.png)

また、調査の目的に応じて素早く画面配置を切り替えられるよう、以下のプリセットレイアウトが登録されています。キーボードショートカット（Windows/Linux: `Ctrl+1~3`、macOS: `Cmd+1~3`）でも切り替え可能です。

| レイアウト名 | ショートカット | 構成 | 用途 |
| :--- | :--- | :--- | :--- |
| **Default layout** | `Ctrl+1` / `Cmd+1` | タイムラインビュー + ログビュー + ヒストリービュー | タイムラインを俯瞰しながら、選択したリソースのログと変更履歴を同時に確認する標準的なレイアウトです。 |
| **State view layout** | `Ctrl+2` / `Cmd+2` | タイムラインビュー + ヒストリービュー | リソースの状態遷移やマニフェスト差分の追跡・比較に集中したい場合に適したレイアウトです。 |
| **Topology view layout** | `Ctrl+3` / `Cmd+3` | タイムラインビュー + トポロジービュー | 特定時点におけるリソース間の依存関係や親子関係を視覚的に把握したい場合に適したレイアウトです。 |
