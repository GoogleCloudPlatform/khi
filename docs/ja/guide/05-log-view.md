# ログビュー

[< 前へ: フィルタリング](./04-filtering.md) | [次へ: ヒストリービュー >](./06-history-view.md)

---

ログビューは、タイムライン上で発生した個々の構造化ログを時系列で閲覧・調査するための画面です。タイムライン上のリソース選択とシームレスに連動し、対象リソースに関連するログだけを素早く絞り込んで詳細を確認できます。

## 画面構成

![ログビューの画面構成](/docs/ja/images/log-view-structure.png)

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **タイムライン連動フィルタ切り替え** | タイムラインで選択中のリソースに連動してログを絞り込むかどうかを切り替えます。 |
| **2** | **子孫ログ包含切り替え** | 選択中のタイムライン配下にある子孫要素（コンテナやサブリソースなど）のログを含めるかどうかを切り替えます。 |
| **3** | **ログ件数ヘッダー** | 全体ログ件数と、現在の選択・フィルタによって抽出されたログ件数を表示します。 |
| **4** | **ログリスト** | 時系列順に並んだログの一覧です。重大度、発生時刻、サマリーが表示されます。 |
| **5** | **ログホバーポップアップ** | ログリストの行にマウスカーソルを合わせた際、ログサマリーの詳細を折り返して表示します。 |
| **6** | **ログプロパティ** | 選択中のログのログタイプ、重大度、タイムスタンプ、関連リソース一覧を表示します。 |
| **7** | **ログ詳細表示ペイン** | 選択中の構造化ログの全フィールドを YAML 形式で詳細表示します。 |

## ログのフィルタリングとタイムライン選択

KHI はデフォルトの状態で、タイムライン上で選択されているリソースに関連するログのみをログビューに表示します。選択されたタイムラインは薄緑色でハイライト表示されます。

### 1. 選択したリソースとその子孫要素のログ表示（デフォルト）

初期状態では、選択したタイムライン本体に加えて、その子要素に関連するログもすべて表示されます。

![選択リソースと子孫のログ表示](/docs/ja/images/log-filter-pod-with-children.png)

上記の例では、クラスタ全体の 180,965 件のログのうち、選択した Pod およびその子コンテナに関連する 467 件のログが抽出されてログビューに表示されています。

### 2. 子孫要素の除外（リソース単体への絞り込み）

選択したタイムライン直下のログのみを確認したい場合は、ヘッダーの「子孫ログ包含切り替えボタン（番号 2）」をクリックします。

![子孫ログを除外して Pod 単体に絞り込み](/docs/ja/images/log-filter-pod-only.png)

子孫要素のログが除外され、Pod 単体に関連する 77 件のログのみに絞り込まれます。コンテナのログを除いて Pod 自体の状態変化ログだけを素早く追跡したい場合に便利です。

### 3. タイムライン連動フィルタの解除（全ログ表示）

「タイムライン連動フィルタ切り替えボタン（番号 1）」をクリックすると、タイムライン選択による絞り込みが解除され、すべてのタイムラインのログが時系列で表示されます。

![タイムライン連動フィルタを解除して全ログを表示](/docs/ja/images/log-filter-all-timelines.png)

クラスタ全体で同じ時刻周辺に何が起きていたかを横断して確認したい場合に役立ちます。全ログ表示にすると件数が非常に多くなるため、ツールバーのログ検索と組み合わせて活用するのが効果的です。

## ログリスト

![ログリストの各要素](/docs/ja/images/log-list-elements.png)

ログリストの各行には、ログの識別と把握を容易にする以下の情報が表示されます。

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **ログタイプ** | ログの種類を表すカラーバーです。タイムライン上のイベント菱形マーカーの下側の色と一致します。 |
| **2** | **ログの重大度** | ログの重大度を表すインジケータです。イベント菱形マーカーの上側の色と一致します。 |
| **3** | **タイムスタンプ** | ログが記録された時刻を表示します。 |
| **4** | **ログサマリー** | 構造化ログから自動生成された 1 行の要約テキストです。 |

## 関連リソース

KHI では、1 つのログが複数のリソースに紐づくことがあります。例えば kubelet が Pod を起動したログは、Pod そのものに関連するだけでなく、ノード上で動作する kubelet デーモンにも関連しているといえます。

KHI ではこのようなログを複数のリソースに自動的に紐づけて管理しており、ログ詳細の「Related resources」リストから各リソースのタイムラインへ素早く移動できます。

![関連リソースの階層表示](/docs/ja/images/log-related-resources.png)

各リソース項目にマウスカーソルを合わせると、そのリソースのクラスタ内での階層構造がポップアップ表示され、リソースの位置関係を直感的に確認できます。
