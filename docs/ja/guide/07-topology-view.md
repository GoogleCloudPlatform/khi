# トポロジービュー

[< 前へ: ヒストリービュー](./06-history-view.md)

---

トポロジービューは、クラスタ内のリソース構成やリソース間の関係性を直感的なトポロジー図として可視化する機能です。タイムライン上で選択されているログの時刻におけるクラスタのステートを再現して描画します。

![トポロジービューの画面](/docs/ja/images/topology-view.png)

## トポロジービューの開き方

ヘッダーの **View** メニューから **Topology view layout** を選択することで、画面右側にトポロジービューを展開できます。

## 特徴と注意点

- **特定時刻のステート再現**: タイムライン上で選択されているログの発生時点における各リソース（Deployment、DaemonSet、Node、Pod、Service 等）の状態や関連性を可能な限り忠実に描画します。
- **パフォーマンスに関する注意**: 巨大なクラスタでリソースのフィルタリングを行わずにトポロジービューを開くと、描画対象ノードが膨大になりブラウザのパフォーマンスが著しく低下する可能性があります。大規模なログデータを調査する際は、事前にツールバーのタイムラインフィルタを用いて調査対象のリソースを絞り込んでからトポロジービューを開くことを推奨します。
