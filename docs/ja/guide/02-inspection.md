# インスペクション

[< 前へ: 画面構成](./01-ui-overview.md) | [次へ: タイムラインビュー >](./03-timeline-view.md)

---

KHI を起動すると、最初にスタート画面が表示されます。この画面から新しいインスペクションを作成したり、保存済みの `.khi` ファイルを読み込んだりできます。

## スタート画面の構成

![スタート画面の構成](/docs/ja/images/startup-elements.png)

| 番号 | 要素名 | 説明 |
| :--- | :--- | :--- |
| **1** | **New Inspection** | Cloud Logging からのログ取得や、JSON Lines 形式の監査ログファイルなどを取り込んで新しいインスペクションを作成します。 |
| **2** | **Open .khi file** | 過去に KHI からエクスポート・保存した `.khi` ファイルを読み込んで開きます。 |
| **3** | **インスペクションリスト** | 処理中および処理完了済みのインスペクション一覧です。「Open」ボタンで可視化画面を開き、「Download」ボタンで `.khi` ファイルとして保存できます。 |

## インスペクションの管理

### インスペクションのリネーム

インスペクションリスト内のタイトル部分をクリックすると、インスペクション名をその場で編集してリネームできます。

![インスペクションのリネーム](/docs/ja/images/startup-rename-inspection.png)

調査対象のクラスタ名やインシデント番号など、後から識別しやすい名前を付けて管理する際に役立ちます。

## 新規インスペクションの作成

KHI では、ログを収集して事前処理済みデータ（`.khi` ファイル）を作成する処理単位を「インスペクション」と呼びます。すでにエクスポート済みの `.khi` ファイルが存在する場合を除き、新規インスペクションを作成することが KHI でログを可視化する最初のステップとなります。

スタート画面の **New Inspection** ボタンをクリックすると、以下の 3 つのステップでインスペクションを設定・作成します。

### 1. クラスタタイプの選択

調査対象となる Kubernetes クラスタの種類を選択します。

![クラスタタイプの選択](/docs/ja/images/startup-new-inspection-cluster.png)

### 2. 取得するログの選択

選択したクラスタタイプに応じて、収集可能なログタイプのリストが表示されます。調査に必要なログにチェックを入れます。

![取得ログの選択](/docs/ja/images/startup-new-inspection-log-types.png)

### 3. パラメータの入力とフィルタプレビュー

選択したログに応じて必要な入力項目が表示されます。調査対象期間、Project ID、クラスタ名、リソースの種類などを入力します。

![パラメータ入力とフィルタプレビュー](/docs/ja/images/startup-new-inspection-parameters.png)

パラメータを入力すると、右側ペインに生成される Cloud Logging フィルタ式がリアルタイムでプレビューされます。

> [!NOTE]
> OSS Kubernetes クラスタを選択した場合は、Cloud Logging のクエリパラメータを入力する代わりに、ローカルの監査ログファイルのアップロード画面が表示されます。

### Job モード用のコマンド取得

ダイアログ右側下部には、入力したパラメータと同等の処理を CLI から直接実行するための Job モードコマンドが表示されます。

CI/CD パイプラインや自動化スクリプト等で `.khi` ファイルを自動生成したい場合は、[Job モードガイド](../setup-guide/job-mode.md) を参照してください。
