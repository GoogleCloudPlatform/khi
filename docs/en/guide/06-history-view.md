# History View

[< Previous: Log View](./05-log-view.md) | [Next: Topology View >](./07-topology-view.md)

---

The History View allows you to trace the chronological revision history of observed resource state transitions from logs and inspect the detailed manifest diffs introduced by each change.

## UI Structure

![History View Structure](/docs/en/images/history-diff-structure.png)

The view consists of three primary components:

| Number | Component | Description |
| :--- | :--- | :--- |
| **1** | **Resource Hierarchy Bar** | Displays the full hierarchy of the selected resource. Click to copy the resource path. |
| **2** | **Changes List** | Displays the list of revisions recorded for this resource. |
| **3** | **Manifest Diff Viewer** | Shows the line-by-line manifest diff introduced by the selected revision. |

## Changes List

The changes list shows all resource modification events extracted from sources like Kubernetes audit logs:

![Changes List Elements](/docs/en/images/history-list-elements.png)

| Number | Component | Description |
| :--- | :--- | :--- |
| **1** | **Revision Index** | The sequential index number of the revision, matching the number at the right end of revision bars on the timeline. |
| **2** | **Diff Indicator** | Indicates whether an actual manifest difference occurred in this revision. A green icon indicates that changes were detected. |
| **3** | **Timestamp** | The exact timestamp when the change occurred. |
| **4** | **Verb** | The Kubernetes API operation verb (e.g. Create, Patch, Delete) that triggered the state transition. |
| **5** | **Principal / User** | The ServiceAccount, Node, or User identity that executed the modification. |

## Resource Diff

The Manifest Diff Viewer displays changes relative to the previous revision with color highlighting (green for additions, red for deletions).

![Manifest Diff Elements](/docs/en/images/history-diff-elements.png)

| Number | Component | Description |
| :--- | :--- | :--- |
| **1** | **Toggle managedFields** | Toggles the visibility of `metadata.managedFields` generated by Kubernetes. |
| **2** | **Diff Navigation** | Jumps back and forth between diff chunks (hunks) in the manifest. |
| **3** | **Additional Information Field** | Hovering over underlined fields displays detailed contextual metadata in a popover. |
